# RECICLA+ — Diseño

Repositorio oficial de recursos de diseño del proyecto RECICLA+.

Aquí se almacenan los elementos gráficos, presentaciones,
identidad visual, recursos de la aplicación, sitio web y
material utilizado para la comunicación del proyecto.

## Contenido

- Identidad visual
- Presentaciones
- Diseño de la aplicación
- Diseño del sitio web
- Redes sociales
- Recursos gráficos
- Documentación
- Exportaciones
